MY GAMING BLOG — PHASE 3

CONTENTS
- index.html: the plain HTML webpage
- images/: two original SVG illustrations used by the webpage

HOW TO VIEW
1. Extract the ZIP file.
2. Open the MY_GAMING_BLOG folder.
3. Open index.html in a web browser.
